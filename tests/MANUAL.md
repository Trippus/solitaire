# Manuel test før udgivelse

Det, de automatiske tests ikke kan mærke. Tag 10 minutter på en rigtig telefon
(`npm start` og åbn LAN-adressen, eller den installerede app).

## Følelse og lyd
- [ ] Træk med fingeren føles glat; kortene følger fingeren uden at hakke
- [ ] Træk en stak med flere kort, og slip den rigtigt og forkert. Den lander eller glider tilbage
- [ ] Lyde spiller efter første tryk (iPhone kræver et tryk først), og Lyd fra virker
- [ ] Sejrsrunden med hoppende kort kører jævnt

## Skærm
- [ ] Alle 7 bunker er synlige på en lille telefon (iPhone SE-størrelse), også med en lang bunke
- [ ] Vandret på telefon og tablet ser ordentligt ud
- [ ] Venstrehåndet layout spejler bunken og grundbunkerne
- [ ] Notch og hjem-bjælke dækker ikke noget

## App
- [ ] Luk appen midt i et spil → åbn igen → "Fortsæt spillet" viser samme spil
- [ ] Flytilstand: appen starter og kan spilles (efter første åbning online)
- [ ] `?reklame=demo`: fuldskærmsreklame kommer kun mellem to spil og kan lukkes efter 5 sek.
